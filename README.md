# hello-github

一个用于练习 GitHub 工作流的范例项目。

## 功能

运行 `main.py` 会输出一句问候语和今天的日期。

## 使用方法

```bash
python main.py
```

## 项目结构

```
hello-github/
├── README.md      项目说明（本文件）
├── main.py        主程序
├── .gitignore     Git 忽略规则
└── LICENSE        开源协议（MIT）
```

## 练习建议

1. 修改 `main.py` 里的问候语
2. 在 GitHub Desktop 中提交并推送
3. 到 GitHub 网页端刷新，确认改动已同步
